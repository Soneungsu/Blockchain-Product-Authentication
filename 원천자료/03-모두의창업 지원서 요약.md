# 모두의 창업 지원서 요약

서비스 기획자(PO)가 지원사업에 제출한 사업 계획서(2026-09-16 작성)의 기획 관련 내용을 요약한다. 제출 문서는 이름이 포함된 PDF이므로 원본을 저장소에 넣지 않고 기획에 필요한 내용만 옮겼다. 금액과 목표는 검증 전의 계획값이다. 경력 소개 항목은 제외했다.

## 출처

| 항목 | 내용 |
| --- | --- |
| 자료 | 모두의 창업 지원사업 2차 지원서 (일반/기술 분야) |
| 작성일 | 2026-09-16 |
| 확인 방식 | PDF를 이미지로 읽어 요약 (텍스트 추출 불가) |

## 아이디어 배경 (Q2)

* 국내 대형 리셀 플랫폼에서 가품 논란이 반복된다는 인식에서 출발했다. 2022년 온라인 패션 편집숍 티셔츠 가품 건, 2025년 7월 한정판 콜라보 스니커즈 가품 건(정가 200만 원대, 600만 원대 판매, 200% 보상), 이용자가 SNS에 올린 다수 제품 가품 주장 건을 근거로 들었다.
* 공통점은 사람이 눈으로 판별하는 사후 검수에 의존하다 보니 판정 기준이 사건마다 달라지고, 소비자는 거래 이후 보상으로만 문제를 해결받는다는 것이다.
* 생산 단계부터 위조가 불가능한 원본 데이터를 블록체인에 기록하고 거래 시점마다 대조하면 분쟁을 막을 수 있다는 생각으로 서비스를 구체화했다.

## 차별점과 해결하려는 문제 (Q3-1)

* **문제**: 거래 후 사람이 판별, 판정 기준 불일치, 위조품 사후 발견. 브랜드 공식몰에서 벗어나 리셀·중고로 넘어가는 순간 이력이 끊긴다.
* **초기 단계**: 제조사 또는 소규모 리셀 플랫폼이 서비스를 도입하면 판매자들이 QR/NFC로 제품을 등록할 때 운영사가 정품 여부를 검증한다. 신규 제품은 제조사 협력, 기존 제품은 제조사 영수증이나 전문가 감정으로 검증한 뒤 운영사가 블록체인에 기록한다.
* **장기 비전**: 제조사가 생산 단계부터 직접 고유 인증정보를 발급해 기록한다.
* **차별점**: 해외는 글로벌 대형 명품 브랜드 연합(Aura 등) 중심이나 국내에는 없어 K패션 디자이너 브랜드와 리셀 시장을 공략한다. 사후 검수 대신 생산 시점 사전 기록. 신규 제품부터 소급 등록, 협력 채널 순으로 확대한다.

## 수익 모델 (Q3-2)

| 수익원 | 대상 | 방식 |
| --- | --- | --- |
| 브랜드 인증 발급비 | K패션 브랜드(월 생산 1,000~5,000개) | 월 50~100만 원 구독, 소규모 브랜드는 제품당 500~1,000원 |
| 거래 시점 검증 수수료 | 개인, 공식 리셀 채널·리셀 플랫폼·위탁판매점 | 개인 건당 1,000원, API 연동 거래당 500~700원 |
| 검수 인프라 대체 이용료 | 소규모 위탁판매점·병행수입 사업자 | 월 20~50만 원 구독(기존 감정비 제품당 5~15만 원 대비) |

## 사업화 계획 (Q4-1)

| 단계 | 시기 | 내용 | 목표 |
| --- | --- | --- | --- |
| 1단계 | 착수~6개월 | 소규모 명품 위탁판매점·병행수입 셀러 1~2곳을 첫 파트너로 무료 또는 최소 비용 확보. QR 태깅·블록체인 등록·검증 전 과정을 실거래 환경에서 검증. 제3자 감정사 네트워크 구축 | 정량 실적 확보 |
| 2단계 | 6개월~1년 | 브랜드 발급비 유료화, K패션 브랜드 1~2곳 확보, 공식 중고 판매 채널에 API 연동, 거래 검증 수수료 | 월 50~200만 원 |
| 3단계 | 1년 이후 | 브랜드 3~5곳 추가, 위탁판매점 대상 월 구독형 검수 인프라, 중소 리셀 플랫폼 API 연동 확대 | 월 400~950만 원 |

* **기술 방향**: 제조사 관리자 시스템과 소비자·파트너용 검증 앱 2가지 MVP를 최소 비용으로 개발한다. 블록체인은 검증된 퍼블릭·컨소시엄 체인 위에 인증 데이터를 기록한다.
* **손익**: 3~6개월은 지원금으로 PoC를 진행하고, 13개월 이후 월 매출 800만 원 이상이면 손익분기점에 도달한다는 계획이다.

## 확인되지 않은 내용

* 감정비(제품당 5~15만 원), 월 매출 목표, 단가는 근거가 확인되지 않았다.
* 지원서가 QR/NFC라고만 적고 서명 칩 여부는 정하지 않았다.
* 이용자 SNS 글 등 지원서가 인용한 사례의 출처는 확인하지 못했다.
