# 용어집

기획 문서에서 공통으로 쓰는 서비스 용어를 정의한다. 각 문서는 용어를 개별적으로 정의하지 않고 이 문서의 정의를 따른다. 용어에는 추적 ID를 부여하지 않는다.

## 1. 서비스 용어

| 용어 | 뜻 |
| --- | --- |
| 고유번호 | 제조사가 제품마다 발급한 고유한 인증 번호. 정품 여부를 확인하는 기준이 된다 |
| 상품 마스터 | 고유번호를 연결할 상품의 기본 정보(브랜드, 모델, 이미지) |
| 등록 건 | 고유번호 하나를 상품에 연결해 등록한 단위 |
| 원장 | 고유번호 등록 사실을 위·변조할 수 없게 남기는 블록체인 기록. 진위 판단의 기준이다 |
| 원장 기록 | 등록 건의 등록 사실을 원장에 남기는 일 |
| 기록 번호 | 원장에 기록된 건마다 부여되는 고유한 확인 번호(tx 해시). 이 번호로 기록을 찾아 확인할 수 있다 |
| 플랫폼 노출 | 등록 건이 플랫폼의 상품 목록·상세에 보이는 것. 원장 기록이 완료된 건만 노출된다 |
| 등록 이력 | 등록 건별로 등록자, 등록 시각, 기록 번호를 확인할 수 있는 내역 |
| 작업 이력 | 누가 무엇을 했는지 남기는 기록. 등록 작업마다 남는다 |

## 2. 원장 기록 상태

등록 건의 원장 기록 진행 상태를 나타내는 값이다. 문서에서는 상태 이름으로 쓰고, 상태값은 필요한 경우에만 병기한다.

| 상태 이름 | 상태값 | 뜻 | 플랫폼 노출 |
| --- | --- | --- | --- |
| 기록 대기 | `PENDING` | 원장에 기록을 요청하고 결과를 기다리는 상태 | 노출 안 됨 |
| 기록 완료 | `CONFIRMED` | 원장에 기록이 끝난 상태 | 노출됨 |
| 기록 실패 | `FAILED` | 원장에 기록하지 못한 상태 | 노출 안 됨 |
