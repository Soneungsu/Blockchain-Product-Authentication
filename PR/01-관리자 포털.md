# 관리자 포털 (Product Requirement)

관리자(ACTOR-001)가 사용하는 관리자 포털의 로그인, 상품 마스터, 고유번호 등록, 이력, 조회 횟수 확인에 대한 제품 요구사항이다. 개별 Product Requirement는 `PR-###` 형식을 사용하며, 근거(`based_on`)는 `BR-###`만 갖는다. 관리 기준은 `BR/08-업무 규칙 및 정책.md`의 「2. ID 스키마 및 넘버링 규칙」 중 「5. Product Requirement ID」, 근거 표기 방식은 「3. 추적성 규칙」 중 「4. `based_on` 사용 기준」을 따른다. 원장 기록과 무효 처리는 `02-원장 기록.md`에서 다룬다.

| --- | --- | --- | --- |
| PR-001 | 관리자 로그인 화면에서 운영 측이 발급한 계정으로 인증하고, 인증에 성공하면 관리자 메인(수행할 작업 선택 화면)으로 이동한다. 인증에 실패하면 로그인 화면에 머문다 | BR-001 — 관리자 로그인 | |
| PR-002 | 로그인하지 않은 상태에서 관리 화면이나 관리 기능을 요청하면 로그인 화면으로 이동시키고 관리 기능을 실행하지 않는다 | BR-001 — 관리자 로그인 | |
| PR-003 | 회원가입 화면과 경로를 제공하지 않는다. 관리자 계정은 단일 역할이며 화면에서 역할을 구분하지 않는다 | BR-001 — 관리자 로그인 | |

| PR-005 | 고유번호 등록 화면에서 저장된 상품 마스터 목록에서 연결할 상품을 선택할 수 있다. 상품 마스터가 없으면 상품 마스터 등록 화면으로 이동할 수 있다 | BR-002 — 상품 마스터 등록 | |
| PR-006 | 상품 마스터를 수정·삭제할 수 있다. 원장 기록이 연결된(등록 완료된) 상품 마스터는 수정·삭제 기능을 제공하지 않고 불가 사유를 안내하며, 연결되지 않은 상품 마스터만 수정·삭제한다 | BR-010 — 상품 마스터 수정·삭제 제한 | |
| PR-007 | 고유번호를 단건으로 입력해 등록하는 화면을 제공한다. 상품 마스터를 선택하고 고유번호를 입력한다 | BR-016 — 단건·일괄 등록 | |
| PR-008 | 여러 건의 고유번호를 일괄 등록하는 방식을 제공한다. 일괄 등록한 건도 형식 검사, 중복 검사, 최종 확인, 기록 상태 표시를 단건과 같은 규칙으로 거친다 | BR-016 — 단건·일괄 등록 | |
| PR-009 | 입력한 고유번호는 입력 즉시 최소한의 형식 검사를 수행한다. 형식이 맞지 않으면 사유를 화면에 표시하고 해당 건에 대해 원장 기록 요청을 실행하지 않는다. 형식에 맞는 오입력은 이 검사로 검출하지 않는다 | BR-003 — 고유번호 형식 검증, BR-016 — 단건·일괄 등록 | |
| PR-010 | 형식 검사를 통과한 고유번호는 서비스 내 등록 내역과 원장 양쪽에서 중복을 검사한다. 이미 등록된 번호이면 등록을 진행하지 않고 중복임을 안내한다 | BR-004 — 중복 고유번호 차단, BR-016 — 단건·일괄 등록 | |
| PR-011 | 형식·중복 검사를 통과한 건은 원장 기록을 요청하기 전에 최종 확인 화면을 보여 준다. 화면에는 연결할 상품과 등록할 고유번호가 표시되며, 관리자가 확인하고 요청해야만 원장 기록이 요청된다. 이 화면 외에 이중 입력 같은 추가 오입력 방지 단계는 두지 않는다 | BR-009 — 최종 확인 화면, BR-016 — 단건·일괄 등록 | |
| PR-012 | 고유번호는 원문이 아닌 복원할 수 없는 변환값(해시와 salt)으로 저장한다. 원장에도 변환값만 기록하고 개인정보는 기록하지 않는다 | BR-012 — 고유번호 변환값 저장 | |
| PR-013 | 등록 이력 화면은 등록 건별로 등록자, 등록 시각, 기록 번호, 기록 상태를 목록으로 보여 준다 | BR-008 — 등록 이력 조회 | |
| PR-014 | 등록 이력 화면에서 고유번호, 상품명, 등록자, 기간 중 하나 이상으로 검색·필터할 수 있고, 조건에 맞는 등록 건만 표시한다 | BR-017 — 등록 이력 검색·필터 | |
| PR-015 | 등록, 무효 처리 등 관리자 작업을 실행하면 누가 언제 무엇을 했는지 작업 이력으로 자동 기록한다 | BR-018 — 작업 이력 열람 | |
| PR-016 | 작업 이력 화면에서 작업자, 작업 내용, 작업 시각을 시간순으로 열람할 수 있다 | BR-018 — 작업 이력 열람 | |
| PR-017 | 진위 조회가 이루어질 때마다 고유번호별 조회 횟수를 기록한다 | BR-013 — 조회 횟수 확인 | |
| PR-018 | 조회 횟수 화면에서 고유번호별 진위 조회 횟수를 확인할 수 있다. 알림, 통계 대시보드, 이상 여부 자동 탐지는 제공하지 않는다 | BR-013 — 조회 횟수 확인 | |
| PR-039 | 단건 고유번호 등록 화면에서 고유번호와 함께 서비스에 반입된 서명 NFC 칩을 선택해 연결한다. 칩 UID는 필수 입력이며, 비어 있으면 등록을 진행하지 않고 오류를 안내한다. 인증정보가 등록되지 않은 칩은 연결할 수 없다 | BR-023 — 칩 인증정보 연결, BR-016 — 단건·일괄 등록 | |
