# 진위 조회 (Product Requirement)

소비자(ACTOR-002)의 진위 조회 방식별 동작과 결과 표시에 대한 제품 요구사항이다. 열 구성과 근거 표기는 `01-관리자 포털.md`와 같다. 등록 근거 확인(BR-022)은 운영사 수작업이므로 별도 PR을 두지 않는다. 칩 발급·조달 등 제조사·운영사의 오프라인 절차(BR-021)는 서비스가 제공하는 기능이 아니므로, 서비스가 검증하는 부분만 PR로 작성한다.

| ID | 요구사항 | based_on | 비고 |
| --- | --- | --- | --- |
| PR-030 | 소비자가 NFC 칩을 스캔하면 칩의 UID와 스캔 시 칩이 생성한 인증값이 서비스로 전달되어 조회를 수행한다. 인증값은 스캔마다 달라지는 동적 값이다 | BR-019 — 칩 스캔 진위 조회, BR-024 — 칩 인증 검증 | |
| PR-031 | 칩 스캔 조회는 (1) 칩 인증 검증과 훼손 감지 확인, (2) UID에 연결된 등록 건의 무효 처리 여부 확인, (3) 칩 상태 확인, (4) UID에 연결된 등록 건 확인, (5) 원장 대조를 순서대로 수행하고, 앞 단계에서 결과가 정해지면 뒤 단계의 결과는 표시하지 않는다. 예를 들어 칩 상태가 활성이 아니어도 연결된 등록 건이 무효 처리된 건이면 '무효 처리됨'이 우선하고, 연결된 등록 건이 없어도 칩 상태가 활성이 아니면 '인증 중지된 칩'이 우선한다. 어느 하나라도 통과하지 못하면 '정품'으로 표시하지 않는다 | BR-019 — 칩 스캔 진위 조회, BR-014 — 진위 조회 결과 유형, BR-024 — 칩 인증 검증 | |
| PR-032 | 칩 인증 검증이 통과하고 훼손이 감지되지 않았으며, UID에 연결된 등록 건이 있고, 칩 상태가 활성이며, 원장에 등록되어 있고 무효 처리되지 않은 경우에만 결과를 '정품'으로 표시한다 | BR-014 — 진위 조회 결과 유형 | |
| PR-033 | UID에 연결된 등록 건이 무효 처리된 건이면 결과를 '무효 처리됨', 칩 상태가 활성이면서 연결된 등록 건이 없거나 원장에 기록이 없으면 '미등록'으로 표시한다. 등록 정보와 원장 기록이 다르면 '미등록'이 아니라 PR-048에 따라 '정품 인증 실패'로 표시한다. 그 밖의 칩 스캔 결과는 PR-048~050을 따른다 | BR-014 — 진위 조회 결과 유형 | |
| PR-034 | 소비자가 고유번호를 직접 입력하거나 서명이 없는 QR을 스캔해 조회하면 서명 검증 없이 원장 등록 상태만 확인해 '등록된 제품정보'(연결된 상품 정보 표시), '무효 처리됨', '조회 정보 없음' 중 하나로 안내한다. 이 경우 '정품'이나 '등록된 번호'로 표시하지 않으며 스캔한 실물의 진위를 판정하지 않는다 | BR-020 — 서명 없는 조회 결과 안내 | |
| PR-035 | 원장 조회는 기록 상태가 기록 완료인 등록 건만 대상으로 한다. 기록 대기·기록 실패 건은 원장에 등록된 것으로 보지 않으며, 그 건에 연결된 활성 칩을 스캔하면 '미등록'으로 표시한다 | BR-014 — 진위 조회 결과 유형, BR-005 — 원장 기록 상태 구분 | |
| PR-036 | 조회 결과 화면에는 결과 유형과 함께, 서명 검증을 거친 조회인지 여부에 따라 달라지는 안내 문구를 표시한다. 서명 없는 조회 결과에는 스캔한 실물의 정품 여부를 확인하지 않는다는 고지와 정품 확인은 인증 칩 스캔으로 할 수 있다는 안내를 항상 표시한다 | BR-014 — 진위 조회 결과 유형, BR-020 — 서명 없는 조회 결과 안내, BR-028 — 정품이 아닌 결과 안내 | |
| PR-045 | 칩 스캔 조회는 이미 수락한 인증값의 재사용(재전송)을 거부한다. 재사용이 확인되면 결과를 '정품 인증 실패'로 표시한다. 재사용을 판별하는 방식은 칩 모델 확정 후 정한다 | BR-024 — 칩 인증 검증 | |
| PR-046 | 칩 인증 실패, 반입되지 않은 칩, 연결된 등록 건 없음, 비활성 상태 칩 등 조회 실패 사유를 내부적으로 구분해 기록한다. 소비자 화면에는 세부 실패 원인을 노출하지 않는다 | BR-024 — 칩 인증 검증 | |
| PR-047 | 칩 인증 검증 기능은 칩 모델과 인증 방식에 의존하는 부분을 별도 모듈로 분리해, 칩 모델이 바뀌어도 검증 모듈 교체로 대응할 수 있게 한다 | BR-024 — 칩 인증 검증 | |
| PR-048 | 칩 인증 검증에 통과하지 못하거나(반입되지 않은 칩 포함), 칩의 훼손이 감지되거나, UID에 연결된 서비스 등록 정보와 원장 기록이 일치하지 않으면 결과를 '정품 인증 실패'로 표시한다. 이 경우 '정품' 또는 '가품'으로 표시하지 않는다 | BR-014 — 진위 조회 결과 유형, BR-024 — 칩 인증 검증 | |
| PR-049 | 칩 상태가 활성이 아닌 칩(폐기, 분실 등. 상태 값의 종류와 결과 매핑은 OI-037에서 확정)을 스캔하면, 칩 인증 검증과 훼손 감지 확인을 통과했고 연결된 등록 건이 무효 처리된 건이 아닌 경우 연결된 등록 건이 없어도 결과를 '인증 중지된 칩'으로 표시한다. 이 경우 '정품' 또는 '가품'으로 표시하지 않는다 | BR-014 — 진위 조회 결과 유형, BR-025 — 칩 반입·상태 관리 | |
| PR-050 | 웹페이지는 열렸으나 칩에서 인증 정보를 읽거나 전달하지 못한 경우 결과를 '칩 확인 불가'로 표시하고 재시도 방법을 안내한다. 이 경우 '정품' 또는 '가품'으로 표시하지 않는다 | BR-014 — 진위 조회 결과 유형, BR-024 — 칩 인증 검증, BR-028 — 정품이 아닌 결과 안내 | |
| PR-051 | 칩 스캔·QR 스캔·번호 입력 조회 결과에 연결된 등록 건의 상품 상세(브랜드, 모델, 이미지)를 조회 전용으로 보여 준다. 상품 상세는 PR-027의 노출 조건(기록 완료이면서 무효 처리되지 않음)을 충족하는 등록 건만 대상으로 하며, 상품 목록 화면은 제공하지 않는다 | BR-027 — 상품 상세 조회, BR-005 — 원장 기록 상태 구분 | |
| PR-052 | '정품' 결과 화면에 등록 시각과 원장 기록을 확인할 수 있는 기록 확인 링크를 표시한다 | BR-026 — 정품 결과의 근거 확인 | |
| PR-053 | 진위 조회와 상품 상세 조회는 로그인 없이 이용할 수 있으며, 회원가입 화면과 로그인 요구를 두지 않는다 | BR-029 — 로그인 없는 조회 | |
| PR-054 | 칩 스캔·QR 스캔·번호 입력 조회에서 원장 기록이 없는 경우와 서버·네트워크 장애로 원장을 확인하지 못한 경우를 구분한다. 장애로 확인하지 못한 경우에는 결과 유형이 아니라 '일시적으로 확인할 수 없음' 안내를 표시하고 '미등록', '정품 인증 실패', '조회 정보 없음'으로 표시하지 않으며 '정품' 또는 '가품'으로도 표시하지 않는다. 안내에는 다시 시도하는 방법을 포함한다. 장애 판정 기준과 표시 문구는 OI-038에서 확정한다 | BR-014 — 진위 조회 결과 유형, BR-028 — 정품이 아닌 결과 안내 | |
| PR-055 | 칩을 읽지 못해 웹페이지가 열리지 않는 경우를 위해 QR 스캔이나 직접 접속으로 열 수 있는 도움말 안내를 제공할 수 있다. 도움말은 사용 방법과 제품정보 안내용이며 진위 결과를 표시하지 않고 NFC 칩 인증을 대신하지 않는다. 기기·칩별 동작과 제공 방식은 칩 실험 후 확정한다(OI-027, OI-033) | BR-020 — 서명 없는 조회 결과 안내, BR-028 — 정품이 아닌 결과 안내 | |
