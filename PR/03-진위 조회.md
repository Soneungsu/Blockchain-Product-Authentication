# 진위 조회 (Product Requirement)

소비자(ACTOR-002)의 진위 조회 방식별 동작과 결과 표시에 대한 제품 요구사항이다. 열 구성과 근거 표기는 `01-관리자 포털.md`와 같다. 등록 근거 확인(BR-022)은 운영사 수작업이므로 별도 PR을 두지 않는다. 칩 발급·조달 등 제조사·운영사의 오프라인 절차(BR-021)는 서비스가 제공하는 기능이 아니므로, 서비스가 검증하는 부분만 PR로 작성한다.

| ID | 요구사항 | based_on | 비고 |
| --- | --- | --- | --- |
| PR-030 | 소비자가 NFC 칩을 스캔하면 칩이 담은 고유번호와 서명을 서비스로 전달해 조회를 수행한다 | BR-019 — 칩 스캔 진위 조회 | |
| PR-031 | 칩 스캔 조회는 칩 서명 검증과 원장 대조를 모두 수행한다. 어느 한쪽이라도 통과하지 못하면 '정품'으로 표시하지 않는다 | BR-019 — 칩 스캔 진위 조회, BR-014 — 진위 조회 결과 유형 | |
| PR-032 | 칩 서명 검증이 통과하고 원장에 등록되어 있으며 무효 처리되지 않은 경우에만 결과를 '정품'으로 표시한다 | BR-014 — 진위 조회 결과 유형 | |
| PR-033 | 고유번호가 원장에 무효 처리된 건이면 결과를 '무효 처리됨', 원장에 없으면 '미등록'으로 표시한다 | BR-014 — 진위 조회 결과 유형 | |
| PR-034 | 소비자가 고유번호를 직접 입력하거나 서명이 없는 QR을 스캔해 조회하면 서명 검증 없이 원장 등록 여부만 확인해 '등록된 번호', '무효 처리됨', '미등록' 중 하나로 안내한다. 이 경우 '정품'으로 표시하지 않는다 | BR-020 — 서명 없는 조회 결과 안내 | |
| PR-035 | 원장 조회는 기록 상태가 기록 완료인 등록 건만 대상으로 한다. 기록 대기·기록 실패 건은 원장에 등록된 것으로 보지 않는다 | BR-014 — 진위 조회 결과 유형, BR-005 — 원장 기록 상태 구분 | |
| PR-036 | 조회 결과 화면에는 결과 유형과 함께, 서명 검증을 거친 조회인지 여부에 따라 달라지는 안내 문구를 표시한다 | BR-014 — 진위 조회 결과 유형, BR-020 — 서명 없는 조회 결과 안내 | |
