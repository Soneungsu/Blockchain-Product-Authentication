지금까지의 대화를 검토하여 세션 인계 문서를 작성하세요.

## 작성 규칙
- 기존 작성 내용(코드/문서)을 임의로 재해석하거나 추측으로 채우지 말 것. 확인되지 않은 내용은 "확인 필요"로 명시.
- 아래 구조를 따를 것. 각 섹션은 실제로 있었던 내용만 간결하게 정리 (없으면 "해당 없음").

## 문서 구조

```markdown
# Session Handoff — {ISO 8601 타임스탬프}

## 진행 상황 (What happened)
- 이번 세션에서 다룬 주제/작업을 bullet로

## 주요 결정사항 (Decisions)
- 확정된 결정과 그 이유 (Why)

## 변경된 산출물 (Artifacts)
- 수정/생성된 파일 경로, 커밋 여부

## 미해결 이슈 / 확인 필요 (Open questions)
- 결론나지 않은 것, 사용자 확인이 필요한 것

## 다음 단계 (Next steps)
- 다음 세션에서 바로 이어갈 작업 목록 (우선순위 순)
```

## 저장
1. 위 구조로 내용을 작성한다.
2. `.claude/session-history/` 디렉터리가 없으면 생성한다.
3. `.claude/session-history/handoff-{YYYY-MM-DDTHH-mm-ss}.md` 파일로 저장한다 (Write 도구 사용).
4. 저장한 파일 경로와 함께, 작성한 내용을 사용자에게 한국어로 간결하게 보여준다.

인자로 추가 지시사항이 있으면 반영: $ARGUMENTS
