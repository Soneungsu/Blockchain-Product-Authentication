# 약관 및 고객안내문 체계

> 초안. 약관·안내문의 종류와 담을 내용을 정리한 체계이며, 실제 조항과 문구는 법무 검토를 거쳐 확정한다.

서비스 이용자와 이해관계자에게 제시하는 약관과 고객안내문의 종류, 적용 대상, 담아야 할 내용을 정의한다. 약관·안내문에는 추적 ID를 부여하지 않으며, 근거가 되는 정책은 `08-업무 규칙 및 정책.md`의 `POLICY-###`를 따른다. 용어는 `08-업무 규칙 및 정책.md`의 용어집을 따른다.

## 1. 구분 기준

| 구분 | 성격 | 동의 여부 | 예 |
| --- | --- | --- | --- |
| 약관 | 이용자와 운영사 사이의 권리·의무를 정하는 문서 | 이용 전 동의 필요 | 이용약관, 개인정보 처리방침 |
| 고객안내문 | 서비스 이용 중 결과와 유의사항을 알리는 문구 | 동의 불필요, 해당 화면에서 노출 | 진위 조회 결과 안내, 원장 기록 안내 |

## 2. 문서 체계

Phase 1은 관리자(ACTOR-001)가 계정으로 등록하고 소비자(ACTOR-002)가 가입 없이 조회하는 범위다(`03-사업 범위 및 스코프 경계.md`). 회원가입, 거래, 결제, 협력사 연동은 Phase 2이므로 관련 약관은 Phase 2부터 적용한다. Phase 1에서 어떤 약관을 어떤 방식으로 제시해야 하는지는 법무 검토 후 확정한다.

| 구분 | 문서 | 적용 대상 | 노출 시점 | 적용 Phase |
| --- | --- | --- | --- | --- |
| 약관 | 서비스 이용약관 | ACTOR-002 소비자 (Phase 2부터 ACTOR-004 판매자 포함) | 서비스 이용 시작 시 (Phase 2 회원가입 시) | Phase 1 조회 이용 조건은 법무 검토 후 확정, Phase 2 가입·거래로 확대 |
| 약관 | 개인정보 처리방침 | 개인정보를 수집·처리하는 이용자 | 상시 열람 (Phase 2 회원가입 시 동의) | Phase 1 수집 범위(관리자 계정, 조회 기록 등)는 법무 검토 후 확정 |
| 약관 | 제조사 이용약관 | ACTOR-003 제조사 | 제조사 이용 시작 시 | Phase 2 (Phase 1은 운영사가 파트너 제품의 등록을 대행하며, 제조사·파트너와 어떤 계약 관계를 맺을지는 법무 검토 후 확정) |
| 약관 | 협력사 연동 약관 | ACTOR-005 협력사 | 연동 계약 체결 시 | Phase 2 |
| 약관 | 거래·결제 이용약관 | ACTOR-002 소비자, ACTOR-004 판매자 | 거래, 결제 시작 시 | Phase 2 |
| 고객안내문 | 진위 조회 결과 안내 | 조회하는 모든 이용자 | 진위 조회 결과 화면 | Phase 1 |
| 고객안내문 | 원장 기록 안내 | 모든 이용자 | 기록 확인 링크 진입 시, 상품 상세 | Phase 1 |
| 고객안내문 | 개인정보 및 데이터 처리 안내 | 모든 이용자 | 조회 화면 하단, 처리방침 링크 (Phase 2 가입 화면 포함) | Phase 1 |
| 고객안내문 | 이용 유의사항 안내 | 모든 이용자 | 서비스 첫 이용, 상품 상세 | Phase 1 |
| 고객안내문 | 관리자 업무 유의 안내 | ACTOR-001 관리자 | 원장 기록 요청 전 최종 확인 화면, 무효 처리 화면 | Phase 1 |

내부 운영 기준(관리자 작업 규칙 등)은 약관이 아닌 `08-업무 규칙 및 정책.md`에서 관리한다.

## 3. 약관별 담을 내용

### 3.1 서비스 이용약관

| 항목 | 내용 |
| --- | --- |
| 목적·정의 | 서비스의 목적, 고유번호·원장·기록 번호 등 용어의 정의 |
| 서비스 범위 | 제공 기능과 제공하지 않는 기능. Phase 1은 상품 조회와 진위 조회이며 거래·결제는 Phase 2에서 추가 |
| 이용자 의무 | 계정 관리, 허위 정보 등록 금지, 위조품 유통 금지 |
| 진위 확인의 의미 | 진위 결과는 원장에 기록된 정품 인증정보와의 대조에 따른 인증 결과이며, 원장 기록이 진위의 기준임 (POLICY-001, POLICY-012) |
| 책임 제한 | 원장 대조 결과의 범위, 번호 복제 등 서비스가 보증하지 않는 사항과 운영사의 책임 범위 |
| 서비스 변경·중단 | 운영 변경, 점검, 장애 시 처리 |
| 분쟁 해결 | 이의 제기 절차, 준거법, 관할 |

### 3.2 개인정보 처리방침

| 항목 | 내용 |
| --- | --- |
| 수집 항목·목적 | 수집하는 정보와 이용 목적. 유저는 익명 ID만 사용하며 원장에는 개인정보를 기록하지 않음 (POLICY-005) |
| 보유·이용 기간 | 항목별 보유 기간과 파기 기준 |
| 제3자 제공·위탁 | 협력사 연동, 외부 시스템 위탁 여부 |
| 원장 기록 처리 | 원장에는 고유번호 변환값, 상품, 등록 시각만 남고 한 번 기록된 내용은 수정·삭제되지 않음 (POLICY-003, POLICY-005) |
| 이용자 권리 | 열람·정정·삭제 요구 방법과 처리 기준 |

### 3.3 제조사 이용약관

| 항목 | 내용 |
| --- | --- |
| 고유번호 발급·등록 책임 | 제조사가 발급한 고유번호의 정확성과 진정성 책임. 칩 부착 |
| 등록 후 처리 | 등록된 기록은 수정·삭제되지 않으며 오등록은 '무효' 기록을 추가해 처리 (POLICY-003, POLICY-010) |
| 브랜드 정보 이용 | 상품 마스터(브랜드, 모델, 이미지)의 이용 범위와 권리 |
| 비용·정산 | 등록에 따른 비용 부담과 정산 기준 |

## 4. 고객안내문별 담을 내용

| 안내문 | 안내 내용 |
| --- | --- |
| 진위 조회 결과 안내 | 결과 유형별(정품 / 무효 처리됨 / 미등록 / 정품 인증 실패 / 인증 중지된 칩 / 칩 확인 불가) 의미와 표시 문구, 등록 시각, 기록 확인 링크. 결과가 원장 대조에 따른 정품 인증 결과임을 안내 (POLICY-012) |
| 원장 기록 안내 | 원장(Base 메인넷)과 기록 번호의 의미, 기록은 수정·삭제되지 않고 추가로만 남는다는 안내 (POLICY-003) |
| 개인정보 및 데이터 처리 안내 | 익명 ID 사용, 고유번호는 변환값으로 저장, 개인정보는 원장에 기록되지 않는다는 안내 (POLICY-005) |
| 이용 유의사항 안내 | 고유번호 직접 입력이나 서명 없는 QR 스캔 조회는 정품 인증이 아니라 등록된 제품정보 확인이며, QR과 번호는 복사될 수 있어 스캔한 실물의 정품 여부를 확인하지 않는다는 점. '정품' 판정은 서명 칩을 스캔한 경우에만 표시된다 (POLICY-012, POLICY-016) |
| 관리자 업무 유의 안내 | 원장 기록 요청 후에는 수정·삭제할 수 없다는 안내, 오등록 시 '무효' 기록으로 처리한다는 안내 (POLICY-006, POLICY-008, POLICY-010) |

## 5. 진위 조회 결과별 안내 문구 방향

| 결과 유형 | 안내 방향 |
| --- | --- |
| 정품 (칩 스캔) | 표시 문구는 '정품'(POLICY-012)이며, 칩 서명 검증과 원장 기록 대조를 모두 통과했음을 함께 설명하고 등록 시각과 기록 확인 링크를 안내 |
| 등록된 제품정보 (번호 입력·QR 스캔) | 등록된 제품정보를 보여 주며, 스캔한 실물의 정품 여부를 확인하지 않는다는 점과 정품 판정은 서명 칩이 부착된 제품의 칩을 스캔해야 받을 수 있음을 안내 (POLICY-016) |
| 무효 처리됨 (칩 스캔·번호 입력·QR 스캔) | 등록 후 무효로 처리된 번호임을 알리고 정품으로 보증할 수 없음을 안내 |
| 미등록 (칩 스캔) | 원장에 등록되지 않은 번호임을 알리고 정품 여부를 판단할 수 없음을 안내 |
| 정품 인증 실패 (칩 스캔) | 정품임을 확인하지 못했음을 알리되 가품이라는 뜻이 아님을 안내하고, 칩 훼손이나 인증 불일치가 원인일 수 있다는 점과 재시도·문의 방법을 안내 (POLICY-012) |
| 인증 중지된 칩 (칩 스캔) | 이 칩의 인증이 중지되었음을 알리고 정품 여부를 판단할 수 없음을 안내. 가품이라는 뜻이 아님을 함께 안내 (POLICY-012) |
| 칩 확인 불가 (칩 스캔) | 칩을 읽지 못했음을 알리고 다시 스캔하는 방법(칩에 기기를 가까이 대는 위치, 기기의 NFC 설정)을 안내. 정품·가품 어느 쪽도 표시하지 않음 (POLICY-012) |
| 조회 정보 없음 (번호 입력·QR 스캔) | 조회할 수 있는 등록 정보가 없음을 알리되 위조나 가품을 암시하는 표현은 쓰지 않고, 정품 여부는 이 조회로 판단할 수 없음을 안내 (POLICY-016) |

## 6. 작성 원칙

* 약관은 이용자가 이해할 수 있는 표현으로 쓰고, 법적 표현은 법무 검토를 거쳐 확정한다.
* 서비스의 정품 인증은 원장 기록을 기준으로 하며, 진위 결과에는 원장 대조에 따른 인증이라는 설명을 함께 제시한다. QR·번호 입력 조회의 한계 등 이용 시 유의할 점은 이용 유의사항 안내에서 고지한다.
* 법률 판단이 필요한 조항(책임 제한, 개인정보 수집 범위, 표시 문구의 적정성 등)은 이 문서에서 확정하지 않고 법무 검토를 거쳐 확정한다.
* 안내문은 결과가 표시되는 화면에서 바로 보이게 하고, 자세한 내용은 약관·처리방침으로 연결한다.
* 약관·안내문 문구가 정책과 다르면 `08-업무 규칙 및 정책.md`를 기준으로 한다.
