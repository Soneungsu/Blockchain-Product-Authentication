# 관리자 유저 스토리 (ACTOR-001)

`01-저니.md`의 단계와 PERSONA-001의 Needs를 근거로 도출한 유저 스토리다. 스토리 한 건은 하나의 Actor와 하나의 목적만 담으며, Business Requirement는 이 문서의 `STORY-###`를 `based_on`으로 참조한다(ID 스키마 §13, 추적성 §3). 용어(원장, 기록 번호, 기록 대기·기록 완료·기록 실패 등)는 `규칙/03-용어집.md`를 따른다.

* Actor: ACTOR-001 — 관리자
* 보조 Persona: PERSONA-001 — 등록 담당 운영자
* 범위: Phase 1 (MVP)

## 스토리 상세

### STORY-001 — 로그인

| 항목 | 내용 |
| --- | --- |
| Actor | ACTOR-001 — 관리자 |
| 스토리 | 관리자로서, 운영 측에서 받은 계정으로 로그인하여 관리 기능을 사용하고 싶다 |
| 목적 | 허가된 사람만 등록 작업을 수행하도록 한다 |
| 확인 기준 | 운영 측에서 미리 만들어 준 계정으로 로그인할 수 있다 · 로그인하지 않으면 관리 기능을 쓸 수 없다 · 관리자는 단일 역할이다 |
