# 소비자 유저 스토리 (ACTOR-002)

`01-저니.md`의 단계와 PERSONA-002·PERSONA-003의 Needs를 근거로 도출한 유저 스토리다. 스토리 한 건은 하나의 Actor와 하나의 목적만 담으며, Business Requirement는 이 문서의 `STORY-###`를 `based_on`으로 참조한다(`08-업무 규칙 및 정책.md`의 「2. ID 스키마 및 넘버링 규칙」 중 「13. Story ID」, 「3. 추적성 규칙」 중 「3. 관계 정의」). 용어(원장, 기록 번호, 칩 스캔 조회, 진위 조회 등)는 `08-업무 규칙 및 정책.md`의 용어집을 따른다.

* Actor: ACTOR-002 — 소비자
* 보조 Persona: PERSONA-002 — 구매 전 확인형 소비자, PERSONA-003 — 보유 제품 확인형 소비자
* 범위: Phase 1 (MVP)

## 스토리 상세

### STORY-012 — 칩 스캔 진위 조회

| 항목 | 내용 |
| --- | --- |
| Actor | ACTOR-002 — 소비자 |
| 스토리 | 소비자로서, 제품에 부착된 NFC 칩을 스캔해 진위를 조회하고 싶다 |
| 목적 | 사려는 제품이나 가진 제품이 정품인지 확인한다 |
| 확인 기준 | 칩을 스캔하면 칩 인증 검증과 훼손 확인, 칩에 연결된 등록 건과 칩 상태 확인, 원장 대조를 모두 수행한다 · 모두 통과한 경우에만 '정품'으로 표시한다 |

### STORY-013 — 진위 조회 결과 이해

| 항목 | 내용 |
| --- | --- |
| Actor | ACTOR-002 — 소비자 |
| 스토리 | 소비자로서, 조회 결과를 한눈에 이해하고 싶다 |
| 목적 | 결과를 구매 판단에 활용한다 |
| 확인 기준 | 칩 스캔 결과가 정품, 무효 처리됨, 미등록, 정품 인증 실패, 인증 중지된 칩, 칩 확인 불가 중 하나로 표시된다 · 정품 인증 실패, 인증 중지된 칩, 칩 확인 불가는 '정품' 또는 '가품'으로 표시하지 않는다 |

| 항목 | 내용 |
| --- | --- |
| Actor | ACTOR-002 — 소비자 |

### STORY-015 — QR·번호 조회로 제품정보 확인

| 항목 | 내용 |
| --- | --- |
| Actor | ACTOR-002 — 소비자 |
| 스토리 | 소비자로서, QR을 스캔하거나 고유번호를 입력해 등록된 제품정보를 확인하고 싶다 |
| 목적 | 칩을 스캔하지 않아도 제품이 어떤 상품으로 등록되어 있는지 안다 |
| 확인 기준 | 서명이 없는 QR 스캔이나 고유번호 직접 입력으로 조회하면 '정품'으로 표시하지 않고 등록된 제품정보만 안내한다 · 결과가 등록된 제품정보, 무효 처리됨, 조회 정보 없음 중 하나로 표시된다 · 스캔한 실물의 정품 여부를 확인하지 않는다는 고지가 함께 표시된다 |
