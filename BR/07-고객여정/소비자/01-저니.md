# 소비자 고객 저니 (ACTOR-002)

소비자(ACTOR-002)가 제품의 정품 여부를 조회하고, 결과와 근거를 확인해 구매 판단이나 보유 제품 확인에 활용하는 과정을 단계별로 정리한다. 유저 시나리오·유저 플로우·유저 스토리를 도출하는 근거 자료이며 별도 ID는 부여하지 않는다(`08-업무 규칙 및 정책.md`의 「2. ID 스키마 및 넘버링 규칙」 중 「13. Story ID」). 용어(원장, 기록 번호, 칩 스캔 조회, 진위 조회, 칩 인증정보, 칩 상태 등)는 `08-업무 규칙 및 정책.md`의 용어집을 따른다.

## 1. 저니 개요

| 항목 | 내용 |
| --- | --- |
| Actor | ACTOR-002 — 소비자 (대응 이해관계자: 일반 소비자) |
| 페르소나 | PERSONA-002 — 구매 전 확인형 소비자, PERSONA-003 — 보유 제품 확인형 소비자 |
| 범위 | Phase 1 (MVP). 회원가입과 로그인 없이 조회한다. 거래·결제는 Phase 2다 |
| 이용 환경 | 스마트폰으로 제품의 칩을 스캔하거나 QR을 스캔하거나 고유번호를 입력해 웹에서 조회 |
| 여정 목표 | 사려는 제품 또는 가진 제품이 정품인지 확신하고, 그 근거를 확인한다 |
| 시작 조건 | 서명 NFC 칩이 부착된 제품(또는 그 제품의 QR·고유번호)을 손에 두고 있다 |
| 종료 조건 | 조회 결과와 그 의미를 이해하고, 필요한 경우 근거(등록 시각, 기록 확인 링크)와 상품 상세를 확인했다 |
| 관련 원칙 | 원장이 진위의 기준 / '정품'은 칩 인증 검증, 훼손 미감지, 등록 건·칩 상태 확인, 원장 대조를 모두 통과한 칩 스캔 조회에만 표시 / 서명이 없는 QR·번호 조회는 등록된 제품정보만 안내하고 실물 진위를 판정하지 않음 / 정품 아님으로 끝난 결과도 '가품'으로 단정하지 않음 |

## 2. 단계 요약

```
① 조회 수단 선택
↓
② 조회 실행 (칩 스캔 / QR 스캔 / 번호 입력)
↓
③ 결과 확인
↓
④ 근거 확인 (정품 결과일 때)
↓
⑤ 상품 상세 확인
↓
⑥ 정품으로 확인되지 않을 때의 다음 행동 (조건부)
```

①②③이 한 번의 조회 사이클이다. ④는 '정품' 결과에서, ⑥은 정품으로 확인되지 않은 결과에서만 발생하는 조건부 단계다. ⑤는 조회 결과에 상품 정보가 연결된 경우에 볼 수 있다.

## 3. 단계별 저니

### ① 조회 수단 선택

| 항목 | 내용 |
| --- | --- |
| 소비자 목표 | 지금 확인할 수 있는 가장 믿을 수 있는 방법으로 제품을 조회한다 |
| 행동 | 제품에 부착된 인증 칩을 스캔하거나, 제품의 QR을 스캔하거나, 고유번호를 입력할지 고른다 |
| 접점 | 제품에 부착된 인증 칩, QR, 제품 표기 |
| 시스템 반응 | 회원가입이나 로그인을 요구하지 않고 조회로 바로 이어지게 한다 |
| 생각 | "이 제품이 정품인지 가입 없이 바로 확인하고 싶다" |
| 감정 | 기대, 약간의 불안 |
| Pain Point | 정품 여부를 확인할 방법 자체가 없거나, 인증 서비스를 이용해도 위조품을 받을 수 있다는 불안 |
| 기회 | 가입 절차 없이 바로 조회할 수 있는 진입 |

### ② 조회 실행

| 항목 | 내용 |
| --- | --- |
| 소비자 목표 | 선택한 수단으로 제품을 조회한다 |
| 행동 | 칩에 스마트폰을 가까이 대 스캔하거나, QR을 스캔하거나, 고유번호를 입력한다 |
| 접점 | 스마트폰, 웹 조회 화면 |
| 시스템 반응 | 칩 스캔이면 칩 인증 검증과 훼손 확인, 등록 건·칩 상태 확인, 원장 대조를 수행한다. QR 스캔과 번호 입력이면 서명 검증 없이 등록 상태만 확인한다. 조회 횟수를 기록한다 |
| 생각 | "결과가 빨리 나왔으면 좋겠다" |
| 감정 | 긴장 |
| Pain Point | 칩을 읽지 못하면 결과를 얻을 수 없다 |
| 기회 | 칩을 읽지 못한 경우 재시도 방법을 안내 |

### ③ 결과 확인

| 항목 | 내용 |
| --- | --- |
| 소비자 목표 | 결과를 한눈에 이해한다 |
| 행동 | 화면에 나온 결과 유형과 안내 문구를 읽는다 |
| 접점 | 조회 결과 화면 |
| 시스템 반응 | 칩 스캔은 '정품', '무효 처리됨', '미등록', '정품 인증 실패', '인증 중지된 칩', '칩 확인 불가' 중 하나를 보여 준다. QR 스캔과 번호 입력은 '등록된 제품정보', '무효 처리됨', '조회 정보 없음' 중 하나를 보여 주고, 스캔한 실물의 정품 여부를 확인하지 않는다는 고지를 함께 표시한다 |
| 생각 | "이 결과가 무슨 뜻인지 바로 알고 싶다" |
| 감정 | 안도('정품') 또는 혼란(정품이 아닌 결과) |
| Pain Point | 정품이 아닌 결과가 나왔을 때 가품이라는 뜻인지 단순히 확인하지 못한 것인지 구분되지 않는다 |
| 기회 | 결과별 의미를 분명히 안내하고, '정품'이나 '가품'으로 단정하지 않는 결과를 명확히 구분 |

### ④ 근거 확인 (정품 결과일 때)

| 항목 | 내용 |
| --- | --- |
| 소비자 목표 | 결과의 근거를 스스로 확인하거나 다른 사람에게 보여 준다 |
| 행동 | 결과 화면의 등록 시각과 기록 확인 링크를 확인한다 |
| 접점 | 결과 화면, 원장 기록 확인 링크 |
| 시스템 반응 | '정품' 결과에 등록 시각과 기록 확인 링크를 함께 보여 준다 |
| 생각 | "이 결과가 진짜 기록에 근거한 것인지 직접 확인하고 싶다" |
| 감정 | 신뢰 |
| Pain Point | 근거를 볼 수 없으면 결과를 믿기 어렵다 |
| 기회 | 원장 기록을 외부에서 확인할 수 있는 링크 제공 |

### ⑤ 상품 상세 확인

| 항목 | 내용 |
| --- | --- |
| 소비자 목표 | 조회한 제품이 어떤 상품으로 등록되어 있는지 확인한다 |
| 행동 | 결과에 연결된 상품 상세(브랜드, 모델, 이미지)를 본다 |
| 접점 | 상품 상세 화면 |
| 시스템 반응 | 기록이 완료되고 무효 처리되지 않은 등록 건의 상품 정보를 조회 전용으로 보여 준다. 상품 목록 화면은 Phase 1에서 제공하지 않는다 |
| 생각 | "내가 든 제품과 등록된 상품 정보가 같은지 보고 싶다" |
| 감정 | 중립 |
| Pain Point | 등록된 정보와 실물이 다른지 소비자가 스스로 판단해야 한다 |
| 기회 | 브랜드·모델·이미지를 실물과 대조할 수 있게 제공 |

### ⑥ 정품으로 확인되지 않을 때의 다음 행동 (조건부)

| 항목 | 내용 |
| --- | --- |
| 소비자 목표 | 결과의 의미를 오해하지 않고 다음에 무엇을 할지 안다 |
| 행동 | 안내 문구를 읽고, 칩 확인 불가라면 다시 스캔한다 |
| 접점 | 결과 화면의 안내 문구 |
| 시스템 반응 | '정품 인증 실패', '인증 중지된 칩', '미등록', '조회 정보 없음'은 가품이라는 뜻이 아니며 정품 여부를 판단할 수 없음을 안내한다. '칩 확인 불가'는 재시도 방법을 안내한다. 서버·네트워크 장애로 확인하지 못한 경우는 결과 유형이 아니라 '일시적으로 확인할 수 없음' 안내를 표시하며 미등록이나 정품 인증 실패로 보여 주지 않는다. 이 결과들은 '정품' 또는 '가품'으로 표시하지 않는다 |
| 생각 | "위조품인지 그냥 확인이 안 된 건지 알고 싶다" |
| 감정 | 불안, 혼란 |
| Pain Point | 미등록 결과가 나왔을 때 위조품인지 단순 미등록인지 구분되지 않는다 |
| 기회 | 결과별로 가능한 다음 행동을 분명히 안내 |
