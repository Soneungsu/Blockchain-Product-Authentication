# 소비자 유저 시나리오 (ACTOR-002)

`01-저니.md`의 단계를 구체적인 상황과 이야기로 풀어 쓴 시나리오다. 저니 단계와 예외 상황이 누락되지 않았는지 확인하는 근거 자료이며 별도 ID는 부여하지 않는다(`08-업무 규칙 및 정책.md`의 「2. ID 스키마 및 넘버링 규칙」 중 「13. Story ID」). 용어(원장, 기록 번호, 칩 스캔 조회, 진위 조회 등)는 `08-업무 규칙 및 정책.md`의 용어집을 따른다.

* 페르소나: PERSONA-002 — 구매 전 확인형 소비자, PERSONA-003 — 보유 제품 확인형 소비자

* 시나리오는 저니의 ①~⑥ 단계를 기준으로 하며, 정해지지 않은 세부 동작(문의 방법, 안내 문구의 구체적 표현 등)은 시나리오에서 임의로 정하지 않는다

## 시나리오 1. 구매 전에 칩을 스캔해 정품 결과를 받고 근거를 확인한다

**관련 저니 단계:** ① 조회 수단 선택 → ② 조회 실행 → ③ 결과 확인 → ④ 근거 확인

구매 전 확인형 소비자는 사려는 제품을 손에 들고 있다. 제품에 인증 칩이 붙어 있다는 안내를 보고, 가입 없이 스마트폰을 칩에 가까이 댄다. 시스템이 칩 인증 검증, 훼손 확인, 등록 건과 칩 상태 확인, 원장 대조를 모두 수행하고, 모두 통과하자 화면에 '정품'이 표시된다.

소비자는 결과 아래에 나온 등록 시각과 기록 확인 링크를 눌러 원장에 기록되어 있음을 직접 확인하고 구매를 결정한다.

## 시나리오 2. 가진 제품의 정품 결과와 상품 상세를 확인해 다른 사람에게 보여 준다

**관련 저니 단계:** ① 조회 수단 선택 → ② 조회 실행 → ③ 결과 확인 → ④ 근거 확인 → ⑤ 상품 상세 확인

보유 제품 확인형 소비자는 이미 가진 제품이 정품인지 확인하려고 칩을 스캔한다. '정품'이 표시되고, 결과에 연결된 상품 상세에서 브랜드, 모델, 이미지를 실물과 비교한다.

나중에 이 제품을 다른 사람에게 보여 줄 일이 생기면 등록 시각과 기록 확인 링크를 함께 보여 준다. 결과를 받은 사람도 기록 확인 링크로 원장 기록을 직접 확인할 수 있다.

## 시나리오 3. QR을 스캔해 등록된 제품정보를 확인한다

**관련 저니 단계:** ① 조회 수단 선택 → ② 조회 실행 → ③ 결과 확인 → ⑤ 상품 상세 확인

소비자는 제품의 QR을 스마트폰으로 스캔한다. 서명 검증이 없는 조회이므로 화면에는 '정품'이 아니라 '등록된 제품정보'가 표시되고, 연결된 상품 상세(브랜드, 모델, 이미지)를 볼 수 있다.

화면에는 스캔한 실물의 정품 여부를 확인하지 않는다는 고지가 함께 나온다. 정품 확인은 제품의 인증 칩을 스캔해야 한다는 점도 안내된다.

## 시나리오 4. 고유번호를 입력했으나 조회 정보가 없다

**관련 저니 단계:** ① 조회 수단 선택 → ② 조회 실행 → ③ 결과 확인 → ⑥ 정품으로 확인되지 않을 때의 다음 행동

소비자가 제품에 표기된 고유번호를 직접 입력해 조회한다. 원장에 등록되어 있지 않은 번호라 '조회 정보 없음'이 표시된다.

화면은 조회할 수 있는 등록 정보가 없다는 사실과, 이 조회로는 정품 여부를 판단할 수 없다는 점만 안내한다. 가품이라는 뜻으로 읽히는 표현은 쓰지 않는다.

## 시나리오 5. 무효 처리된 제품을 조회한다

**관련 저니 단계:** ② 조회 실행 → ③ 결과 확인 → ⑥ 정품으로 확인되지 않을 때의 다음 행동

소비자가 제품을 조회했더니 '무효 처리됨'이 표시된다. 등록 후 무효로 처리된 번호이며, 정품으로 보증할 수 없다는 안내가 함께 나온다. 이 결과는 상품 정보를 노출하지 않는다.

## 시나리오 6. 칩 인증에 실패하거나 훼손이 감지되어 '정품 인증 실패'가 나온다

**관련 저니 단계:** ② 조회 실행 → ③ 결과 확인 → ⑥ 정품으로 확인되지 않을 때의 다음 행동

소비자가 칩을 스캔했는데 칩 인증 검증에 통과하지 못했거나 칩의 훼손이 감지되었거나 등록 정보와 원장 기록이 일치하지 않아 '정품 인증 실패'가 표시된다.

화면은 정품임을 확인하지 못했다는 사실만 알리고, '정품'이나 '가품'으로 단정하지 않는다. 가품이라는 뜻이 아님과 재시도·문의 방법이 함께 안내된다.

## 시나리오 7. 인증이 중지된 칩을 스캔한다

**관련 저니 단계:** ② 조회 실행 → ③ 결과 확인 → ⑥ 정품으로 확인되지 않을 때의 다음 행동

소비자가 스캔한 칩은 상태가 활성이 아니다. 화면에는 '인증 중지된 칩'이 표시되고, 이 칩으로는 정품 여부를 판단할 수 없다는 점과 가품이라는 뜻이 아님이 안내된다.

## 시나리오 8. 칩을 읽지 못해 다시 스캔한다

**관련 저니 단계:** ② 조회 실행 → ③ 결과 확인 → ⑥ 정품으로 확인되지 않을 때의 다음 행동

소비자가 칩에 스마트폰을 대었지만 인증 정보를 읽지 못해 '칩 확인 불가'가 표시된다. 화면은 다시 스캔하는 방법을 안내하고, 정품·가품 어느 쪽도 표시하지 않는다. 소비자는 안내에 따라 다시 스캔한다.

## 시나리오 9. 칩은 확인되지만 미등록 결과가 나온다

**관련 저니 단계:** ② 조회 실행 → ③ 결과 확인 → ⑥ 정품으로 확인되지 않을 때의 다음 행동

보유 제품 확인형 소비자가 칩을 스캔했더니 '미등록'이 표시된다. 칩에 연결된 등록 건이 없거나 원장에 등록되지 않은 경우다. 화면은 원장에 등록되지 않은 번호임을 알리고 정품 여부를 판단할 수 없다고 안내한다. 위조품인지 단순히 등록되지 않은 제품인지 이 화면만으로는 구분되지 않으므로, 가품이라는 뜻이 아님을 함께 알려 준다.
