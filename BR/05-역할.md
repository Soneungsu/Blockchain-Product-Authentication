# 역할

`04-이해관계자.md`에서 식별된 주체 중, 서비스 또는 업무 과정에서 독립적인 책임과 행위를 수행하는 주체를 Actor로 정의한다. Actor는 Repository 추적성의 뿌리다.

## Actor 목록

| ID | Actor | 대응 이해관계자 | 책임 | 주요 행위 |
| --- | --- | --- | --- | --- |
| ACTOR-001 | 관리자 | 운영사 | 제품의 고유번호를 정확하게 등록하고 원장 기록 결과를 관리한다 | 로그인, 상품 마스터 관리, 고유번호 등록, 원장 기록 결과 확인, 실패 건 재시도, 등록 이력 조회 |
| ACTOR-002 | 소비자 | 일반 소비자 | 제품의 정품 여부를 확인하고 그 결과를 구매 판단에 활용한다 | 상품 목록·상세 조회, 고유번호 진위 조회 |

## Actor로 정의하지 않는 이해관계자

| 이해관계자 | 사유 |
| --- | --- |
| 제조사/브랜드 | Phase 1에서는 운영사가 등록을 대행하므로 서비스 내 독립적인 행위가 없다 |
| 판매자, 협력사 | Phase 2 범위이며 Phase 1에서는 행위가 없다 |
| 블록체인 네트워크 | 사람이 아닌 인프라이며 Actor가 아니다 |
