# 페르소나

Actor를 서비스 이용 방식과 필요한 지원 수준에 따라 구분한 대표 인물이다. Persona는 정확히 하나의 Actor에 종속되며, 고객여정 작성 시 참조할 목표·Needs·Pain Point의 기준이 된다.

## 페르소나 목록

| ID | 페르소나 | 대응 Actor |
| --- | --- | --- |
| PERSONA-001 | 등록 담당 운영자 | ACTOR-001 (관리자) |
| PERSONA-002 | 구매 전 확인형 소비자 | ACTOR-002 (소비자) |
| PERSONA-003 | 보유 제품 확인형 소비자 | ACTOR-002 (소비자) |

## PERSONA-001 등록 담당 운영자 (ACTOR-001 대응)

| 항목 | 내용 |
| --- | --- |
| 이용 방식 | 사무 환경에서 PC 관리자 페이지로 제품 고유번호를 반복 등록한다 |
| 목표 | 오류 없이 빠르게 등록하고, 원장에 기록되었음을 확실하게 확인한다 |
| Needs | 중복 번호가 즉시 걸러질 것, 기록 성공 여부가 명확할 것, 실패 건을 바로 다시 시도할 수 있을 것 |
| Pain Point | 잘못 입력한 번호가 원장에 남으면 정정이 어렵다는 부담, 기록 지연·실패 시 원인을 알기 어려움 |

## PERSONA-002 구매 전 확인형 소비자 (ACTOR-002 대응)

| 항목 | 내용 |
| --- | --- |
| 이용 방식 | 제품을 사기 전에 스마트폰 또는 PC에서 로그인 없이 고유번호를 조회한다 |
| 목표 | 사려는 제품이 정품인지 구매 전에 확신한다 |
| Needs | 조회 결과를 한눈에 이해할 것, 결과의 근거(등록 시각, 기록 링크)를 확인할 것 |
| Pain Point | 정품 여부를 확인할 방법 자체가 없거나, 인증 서비스를 이용해도 위조품을 받을 수 있다는 불안 |

## PERSONA-003 보유 제품 확인형 소비자 (ACTOR-002 대응)

| 항목 | 내용 |
| --- | --- |
| 이용 방식 | 이미 가진 제품이 정품인지 확인하고, 필요하면 근거를 다른 사람에게 보여 준다 |
| 목표 | 내 제품이 정품임을 증명할 수 있는 근거를 확보한다 |
| Needs | 기록의 신뢰성을 스스로 검증할 수 있을 것, 미등록 제품일 때 다음 행동을 안내받을 것 |
| Pain Point | 미등록 결과가 나왔을 때 위조품인지 단순 미등록인지 구분되지 않아 혼란스러움 |
