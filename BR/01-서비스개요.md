# 서비스 개요

## 서비스 정의

**Blockchain Product Authentication**은 제조사가 발급한 고유 인증정보를 블록체인 원장에 등록·기록하여 **제품의 정품을 인증하고**, 소비자와 관련 이해관계자가 고유번호로 조회해 **정품 여부와 유통 이력을 신뢰할 수 있게 하는 플랫폼**이다.

정품 인증은 원장에 등록된 고유번호를 기준으로 한다. Phase 1은 제조사가 출고 시점에 서명 NFC 칩을 부착한 신규 제품만 등록하며, 칩 인증 검증과 원장 대조를 모두 통과해야 '정품'으로 안내한다. 고유번호는 QR 코드 등에도 담을 수 있으나, 서명 검증이 없는 조회(고유번호 직접 입력, 서명 없는 QR 스캔)는 제품정보 접근용이며 등록된 제품정보만 안내하고 실물 진위는 판정하지 않는다.

아래 핵심 기능은 서비스의 전체 지향점이며, Phase 1(MVP)에서 실제로 제공하는 기능은 다음 절 "Phase 1에서 제공하는 기능"과 `03-사업 범위 및 스코프 경계.md`를 따른다.

## Phase 1에서 제공하는 기능

Phase 1은 **관리자 등록 → 원장 기록 → 상품 상세 노출 및 고유번호 조회**를 중심으로 한다.

| 단계 | Phase 1에서 제공하는 것 | Phase 1에서 제공하지 않는 것 |
| --- | --- | --- |
| 관리자 등록 | 상품 마스터와 고유번호를 관리자가 단건 또는 일괄로 등록하고, 원장 기록 요청 전에 최종 확인 | 제조사·판매자·협력사의 직접 등록·연동 |
| 원장 기록 | 등록 건의 원장 기록과 기록 결과(기록 번호) 저장, 실패 건 재시도, 오등록 건의 무효 기록 추가 | 판매 등록·판매 완료·소유권 이전 기록 |
| 상품 노출·조회 | 기록이 완료된 등록 건의 상품 상세 노출(상품 목록 화면은 Phase 2), 진위 조회(칩 스캔은 서명 검증과 원장 대조에 따른 정품 인증 결과, 번호 입력·QR 스캔은 등록된 제품정보 표시, 진위 판정 없음) | 거래, 결제, 실물 검수, 위조품 거래 차단 |

## 핵심 기능

### 1. 정품 인증
- 원장에 등록된 고유번호로 정품 인증하고, 서명 NFC 칩이 부착된 제품은 칩 서명 검증으로 복제 방지까지 확인
- 위조품 거래 차단: 거래 플랫폼을 통한 유통 단계의 지향점이며 Phase 1에서는 제공하지 않는다

### 2. 제품 이력 관리
- 생산 → 유통 → 소비까지 전체 이력 기록 (Phase 1은 '등록'·'무효' 기록만, Phase 2에서 판매·소유권 이전 기록으로 확대)
- 투명한 제품 추적

### 3. 신뢰 기반 거래
- 중고거래 시 제품 신뢰도 확보 (Phase 2)
- 소비자 신뢰 향상

## 기술 기반

- **블록체인**: 등록·무효 기록을 스마트 컨트랙트에 추가 방식으로 남겨 기록의 사후 변경 여부를 외부에서 확인할 수 있게 함. 최초 입력 정보의 진실성은 등록 근거 확인(POLICY-019)으로, 실물과의 연결은 서명 NFC 칩(POLICY-017)으로 다룸 (Base 메인넷, 이더리움 EVM 호환 L2. `03-사업 범위 및 스코프 경계.md` 참조)
- **NFC 보안 칩**: 운영사가 조달해 제조사에 제공하고 제품에 부착. 스캔 시 칩이 생성한 인증값을 서버가 검증하며, 고유번호는 칩에 담지 않고 서버의 매핑으로 연결. Phase 1은 칩이 부착된 제품만 등록하며, Phase 1의 칩 비용은 운영사가 부담
- **QR**: 고유번호를 담아 스캔으로 조회. 서명이 없으므로 제품정보 접근용이며 실물 진위는 판정하지 않음
- **클라우드 플랫폼**: 제조사, 소비자, 운영사 간 데이터 중계
